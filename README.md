## **Overview**
The first Dead or Alive game for Sega Saturn is one of the best fighting games on the system. While it never received an English localization, the game is almost entirely in English, which made it very import-friendly.

This patch translates the last remaining Japanese elements to English:

- All character bios on character select screen translated
- All move lists in Training mode translated
- Name entry instructions translated
- "Save warnings" translated

## **Patching Instructions**

The patch is shipped as an XDelta patch. 

### XDelta Instructions ###

1. Grab an XDelta patching utility like <a href='https://www.romhacking.net/utilities/704/'>Delta Patcher</a>
2. Unzip patch bundle
3. Open **'DeltaPatcher.exe'**
4. For the Original File, locate Track 01 of the original Shinouken disc (for example: <kbd>Shinouken (Japan) (Track 01).bin</kbd>)
5. For the XDelta patch section, locate the <kbd>Ragnagard_English_Translation_v1.0.xdelta</kbd> patch.
6. Click **'Apply Patch'**
7. If successful, Track 01 will be replaced with the patched track.

## Helpful Game Tips ##

1. Play as the bosses
   - Contrary to most English-media sources, the bosses **are** playable in Arcade mode in the Saturn version! This tip came to me in a fever dream where the angel of Sega Saturn romhacking, Bo Bayles, handed me a stone Sega Saturn with the following engraving on the bottom:
  
     - To play as **Lucifer**, highlight Susano, hold **START** and press any button
     - To play as **Behemoth**, highlight Syuten-Dozi, hold **START** and press any button
     - To play as **Eelis**, highlight Benten, hold **START** and press any button
       
3. Move lists
   - During gameplay, if you press **Start** to pause, and then press the **A, B, or C buttons**, the move list for your character will be displayed. In Versus Mode, move lists for both players will be displayed.
4. Character Colorways
   - During character select, pressing any of the six face buttons will select a different colorway for each character
6. The Sega Retro page for this game is excellent, with a great summary of the game's mechanics and full move lists for all characters. I encourage you to check it out <a href=https://segaretro.org/Shinouken>here</a>.
